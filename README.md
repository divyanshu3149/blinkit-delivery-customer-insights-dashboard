# Blinkit Delivery & Customer Insights Dashboard

## Project Objective
This project analyzes Blinkit's delivery operations, customer satisfaction, and product performance using Python and Power BI.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI

## Project Workflow
1. Data Cleaning & Preprocessing
2. Exploratory Data Analysis (EDA)
3. Business Insights Extraction
4. Power BI Dashboard Development
5. Interactive Visualization

## Key Business Questions
- How does delivery performance affect customer ratings?
- Which product categories receive the most orders?
- What delivery statuses impact customer satisfaction?
- How are customer segments distributed?

## Dashboard Features
- KPI cards for orders, revenue, and ratings
- Delivery performance analysis
- Customer segmentation
- Product category insights
- Interactive slicers

## Key Insights
- On-time deliveries receive higher customer ratings.
- Instant & Frozen Food is the top-performing category.
- Slight delivery delays negatively affect customer satisfaction.
