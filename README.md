# Blinkit Delivery & Customer Insights Dashboard

## Project Overview
This project analyzes Blinkit's delivery operations, customer satisfaction, and product performance using Python and Power BI. The goal is to identify operational inefficiencies, customer behavior patterns, and delivery performance insights through Exploratory Data Analysis (EDA) and interactive dashboard visualization.

---

## Business Problem
Blinkit wants to understand how delivery performance affects customer satisfaction and operational efficiency.

---

## Project Objective
- Analyze delivery performance and customer satisfaction
- Identify top-performing product categories
- Understand customer segmentation and order distribution
- Evaluate operational efficiency using delivery status analysis
- Build an interactive Power BI dashboard for business insights

---

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI
- GitHub

---

## Project Workflow
1. Data Collection  
2. Data Cleaning & Preprocessing  
3. Exploratory Data Analysis (EDA)  
4. Business Insights Extraction  
5. Power BI Dashboard Development  
6. Interactive Visualization & Reporting  

---

## Key Business Questions
- How does delivery performance affect customer ratings?
- Which product categories receive the most orders?
- What delivery statuses impact customer satisfaction?
- How are customer segments distributed?
- Which operational factors influence customer experience?

---

## Dashboard Features
- KPI cards for orders, revenue, and ratings
- Delivery performance analysis
- Customer segmentation analysis
- Product category insights
- Customer satisfaction analysis
- Interactive slicers and filters

---

## Key Insights
- On-time deliveries receive higher customer ratings.
- Delayed deliveries negatively impact customer satisfaction.
- Instant & Frozen Food categories generate high order volume.
- Customer sentiment varies across delivery performance categories.
- Operational efficiency directly affects customer experience.
